# PnL Tracker (DonutSMP, Fabric, Minecraft 26.1.2)

HUD overlay in the top-right that tracks your /pay profit & loss: net, received, sent, per-player nets and recent payments.

Commands: `/pnl`, `/pnl reset`, `/pnl toggle`. Stats save to `config/pnltracker.json`.

Built by GitHub Actions (Java 25, Gradle 9.5.1) — see the Actions tab for the jar.
